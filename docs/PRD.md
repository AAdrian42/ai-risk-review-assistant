# AI 智能风控审核助手 PRD

## 1. 背景

信贷违约模型可以输出风险概率，但审核人员仍需要在规则文档、模型报告和历史案例之间来回查找，理解“为什么高风险”和“下一步核验什么”。本产品把规则检索、相似案例与模型解释放到一个审核工作台中。

## 2. 目标用户

- 一线风控审核人员：快速找到规则依据与核验要点。
- 风控策略人员：检查规则命中和模型风险信号是否一致。
- 新员工：通过可引用的问答和案例降低学习成本。

## 3. 核心任务

1. 输入自然语言问题，返回有引用的规则答案。
2. 输入申请特征，返回风险等级、主要风险信号和人工核验建议。
3. 检索相似案例，展示案例结果与差异点。
4. 对低置信度或证据冲突的结果提示人工复核。

## 4. 页面与功能

### 4.1 审核工作台

- 结构化申请表单
- 风险概率或透明启发式分数
- 主要风险因素与保护因素
- Top-K 相似案例
- 辅助审核建议和免责声明

### 4.2 规则问答

- 自然语言输入
- 意图标签、检索耗时、证据得分
- 带条目编号的答案
- 原始证据展开查看

### 4.3 评测与系统信息

- 知识库规模和数据来源声明
- 离线评测结果
- 当前回答模式、模型版本和审计日志状态

## 5. 成功指标

- 规则检索 Hit@3：目标不低于 85%。
- 意图分类准确率：目标不低于 90%。
- 引用完整率：目标 100%。
- 无依据自动决策表述：目标 0。
- 用户任务耗时：需通过后续至少 5 名目标用户的对照实验测量。

## 6. 非目标

- 不接入真实客户数据。
- 不替代现有审批系统或人工最终决策。
- 不把 SHAP 相关性解释为因果关系。
- 不宣称未经用户实验验证的效率提升。

## 7. 验收标准

- 无 API Key 时可以完成三条核心链路。
- 每个回答至少包含一个可展开的证据条目。
- 单笔审核结果明确显示所用模式与适用边界。
- 自动化测试与离线评测均通过。
