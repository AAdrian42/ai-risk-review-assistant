# 本地检索与工作流补充

本次已完成 LangChain InMemoryVectorStore 检索，使用 1024 维归一化字符哈希向量，并与 TF-IDF 候选集合并重排。它是本地内存向量存储，不是 Chroma/FAISS，也不是神经语义 Embedding；中文改写、同义词和跨语言检索仍需进一步验证。

意图路由、风险评分、证据回答和引用校验通过 LangChain RunnableLambda 编排；规则和案例采用分类型检索。模型评分和语言回答分开，最终决定仍由人工作出。新增在线调用超时与重试上限、失败降级和未知引用拦截。

知识库共 2068 条，其中 2048 条为合成案例。评测文件记录的是 17 道作者编写的问题，Hit@3 是目标证据是否进入前三，不等于回答准确率，更不等于 2068 条真实案例全部验证。测试集并非独立盲测。

GPT / Claude 接口代码已实现；由于未配置 API 密钥，本次没有完成在线模型实测。当前网站运行本地证据提取模式。未进行真实用户对照实验，因此不能声称实际提升 60% 或 50%。

提效验证建议：准备相同难度任务，用交叉顺序比较人工查规与助手查规，记录完成时间、正确率和漏查率；报告中位耗时及样本数。效率提升按（基线耗时－助手耗时）/基线耗时计算，且需确认质量没有下降。
